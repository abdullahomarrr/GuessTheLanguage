# Language game data pipeline

This workspace is the offline acquisition and review side of the game. It is
based on the supplied `language_game_data_pipeline.zip`; generated bytecode and
downloaded datasets are intentionally excluded from source control.

## Flow

1. `download_glottolog.py` downloads the official Glottolog tabular exports.
2. `normalize_glottolog.py` produces a provider-neutral language/dialect catalog.
3. `fetch_lingualibre_candidates.py` collects licensed audio candidates and
   retains per-file source, creator, license, and attribution metadata.
   `fetch_tatoeba_sentence_candidates.py` is the preferred small-batch source
   when the game needs complete human-recorded sentences with translations.
4. Humans review candidates. Ingestion never makes a clip playable.
5. Approved records are imported into the repository implementation selected by
   the app (mock today; Postgres/Supabase later).

```bash
python scripts/download_glottolog.py
python scripts/normalize_glottolog.py
python scripts/fetch_lingualibre_candidates.py --iso spa --limit 50
python scripts/fetch_tatoeba_sentence_candidates.py --languages spa,fra,deu --per-language 2
python scripts/acquire_major_language_catalog.py --metadata-only
python scripts/acquire_major_language_catalog.py --max-downloads 10
python scripts/acquire_major_language_catalog.py --skip-metadata --download-provider tatoeba
python scripts/acquire_major_language_catalog.py --skip-metadata --download-provider lingualibre
```

Generated catalog files go in `data/processed/`; candidate queues go in
`data/audio_candidates/`. See `docs/DATA_LAYER.md` for the runtime plug-in points.

`config/major_language_targets.json` defines the resumable expansion tier. The
acquisition command checkpoints after every language and stops cleanly when a
provider throttles requests. Rerun the same command later to continue; stored
files and selected metadata are reused rather than fetched again. Download-only
runs avoid spending metadata quota and can be restricted to one provider.

## Production rule

Audio candidates are not auto-approved. Each recording must pass language,
dialect, transcript, translation, direct-giveaway, quality, and licensing review.
The application publication policy enforces those states before a challenge can
load.
